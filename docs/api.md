## `<svg>`

`<svg>`: vector drawings from SVG text, for apps on eskiu-lang/ui. Svg draws a document
(an icon, a piece, a silhouette) scaled to fit its box, drawn by the platform (Core
Graphics on iOS, Canvas on Android, the browser's SVG on the web).

```eskiu
const string kHeart = "<svg viewBox=\"0 0 24 24\"><path d=\"M12 21 3 12a5 5 0 0 1 9-7 5 5 0 0 1 9 7z\"/></svg>";
Svg(Style{width: 24, height: 24, color: kit.accent}, kHeart);
```

What is drawn: `<path>`, `<rect>`, `<circle>`, `<ellipse>`, `<line>`, `<polyline>` and `<polygon>`, in
`<svg>` and `<g>`, with fill, stroke, stroke-width, opacity, fill-opacity, stroke-opacity,
fill-rule, stroke-linecap, stroke-linejoin, stroke-miterlimit, display, visibility and
transform, as attributes or in a style attribute. Colors are #rgb, #rgba, #rrggbb,
#rrggbbaa, rgb(), rgba(), the basic names, none and currentColor (Style.color). Gradients,
patterns, text, `<use>`, clipping and masks are not drawn (a url() paint is its fallback
color, else none).

### SvgMatrix


An affine transform as SVG writes it: x' = a x + c y + e, y' = b x + d y + f.

### svg_multiply

`m` after `n`: the transform that applies `n` first.

### SvgPaintKind


How a fill or stroke paints: not at all, with a color, or with currentColor (the Svg

### SvgOut

```eskiu
struct SvgOut {
    String text;
    SvgMatrix m;
    bool started;
    double width; double height;
}
```

The display list being written: a "V minx miny width height" line, then for each shape a
paint line and a path line (absolute M, L, C, Q and Z, in viewBox units).

### svg_point

```eskiu

```

Appends `command` and the point (x, y) mapped through the current transform, as two %.6g
numbers; values within 1e-9 of 0 are written as 0.

### svg_move

Starts a new subpath at (x, y): an absolute M command.

### svg_line

```eskiu
void svg_line(SvgOut* o, double x, double y)
```

A straight line to (x, y): an absolute L command.

### svg_close


Closes the current subpath: a Z command.

### svg_cubic

A cubic Bezier curve to (x, y) with control points (x1, y1) and (x2, y2): an absolute C

### svg_quad

```eskiu
void svg_quad(SvgOut* o, double x1, double y1, double x, double y)
```

A quadratic Bezier curve to (x, y) with control point (x1, y1): an absolute Q command.

### svg_arc

```eskiu
void svg_arc(SvgOut* o, double x1, double y1, double rx, double ry, double degrees, bool large, bool sweep, double x2, double y2)
```

An elliptical arc from (x1, y1) to (x2, y2) as cubics, each at most a quarter turn (the
SVG spec's endpoint to center conversion, F.6.5).

### svg_skip

### svg_number

```eskiu

```

Reads the next number (sign, digits, fraction, exponent), after whitespace and at most
one comma, into `out` and moves past it; false, with the cursor unmoved, when no number
follows.

### svg_flag

```eskiu
bool svg_flag(SvgScan* sc, *bool out)
```

An arc's flag: one 0 or 1, which may run into the next number ("a1 1 0 01 1 1").

### svg_length

```eskiu
double svg_length(string text, double fallback)
```

The number `text` starts with, or `fallback` (lengths: "24px" is 24).

### svg_path

```eskiu
void svg_path(SvgOut* o, string d)
```

`d` as absolute moves, lines, cubics and quadratics. Parsing stops at the first error,
keeping what came before it, as browsers do.

### svg_rect

```eskiu
void svg_rect(SvgOut* o, double x, double y, double w, double h, double rx, double ry)
```

A rectangle at (x, y), `w` by `h`, with corners rounded by `rx` and `ry` (a negative one
takes the other's value, both are capped at half the side); nothing when `w` or `h` is
not positive.

### svg_ellipse

```eskiu
void svg_ellipse(SvgOut* o, double cx, double cy, double rx, double ry)
```

An ellipse centered at (cx, cy) with radii `rx` and `ry`, as four arcs; nothing when a
radius is not positive.

### svg_points

```eskiu
void svg_points(SvgOut* o, string points, bool closed)
```

The `points` attribute of a polyline or polygon (x y pairs) as lines, closed when
`closed`; nothing when `points` is null.

### svg_trim

`text` without the blanks around it, in `out`.

### svg_hex_digit

```eskiu
int svg_hex_digit(char c)
```

The value of a hexadecimal digit, or -1 when `c` is not one.

### svg_rgba

### svg_hex

Elements whose content is not drawn.

One shape, if it draws anything: its paint line, then its path line.

The root `<svg>`'s viewBox (else its width and height, else 100 by 100), as the first line.

### svg_attributes

### svg_free_attributes

```eskiu

```

Frees each attribute's name and value and empties `attrs` (its storage is kept).

### svg_past

```eskiu

```

The index just past `end` from `at`, or the text's end.

### svg_compile

```eskiu

```

`svg` (a document's text) as the display list the hosts draw, in `out`; false when it has

### SvgCache

```eskiu
struct SvgCache { String source; String list; double width; double height; }
```

What an Svg element keeps between renders: the document text it last compiled, its
display list and its viewBox size.

### svg_release

```eskiu
void svg_release(*SvgCache cache)
```

Frees an SvgCache and its strings; the Svg element calls it when it goes away.

### Svg

```eskiu
void Svg(Style style, string svg)
```

`svg` (an SVG document's text) drawn in the box `style` gives it, scaled to fit and
centered (the viewBox's "xMidYMid meet"); with only a width or a height, the other follows
the viewBox's proportions. currentColor is `style.color`, black when it is not set. The
document is parsed again only when its text changes.
